Usa fotos propias para representar personas, espacios, productos y trabajos reales. Reserva las imágenes de stock para ideas generales que no pretenden documentar el negocio. Si una foto influye en la confianza o en la decisión de visitar, reservar o comprar, debería acercarse todo lo posible a la realidad.

No hace falta elegir un único tipo para toda la web. La mejor decisión se toma sección por sección.

## Qué aporta una fotografía propia

Una foto real responde preguntas que el texto no puede resolver con la misma rapidez: cómo es el local, quién atenderá, qué tamaño tiene un producto o qué estilo de trabajo ofrece el equipo.

Resulta especialmente útil en:

- Portada y presentación del negocio.
- Página de equipo.
- Instalaciones y acceso.
- Productos y acabados.
- Portfolio y casos.
- Proceso de trabajo.
- Indicaciones para llegar o prepararse.

La imagen no tiene que ser perfecta para resultar útil. Sí debe estar bien iluminada, enfocada y actualizada. Una fotografía antigua que ya no representa el espacio puede crear una expectativa equivocada.

## Cuándo puede servir una imagen de stock

El stock ayuda cuando necesitas acompañar un concepto que no se puede fotografiar de forma directa o cuando todavía no tienes material para una sección secundaria. También puede funcionar en artículos informativos, fondos discretos o recursos editoriales.

Evítalo cuando la imagen parezca una prueba. No uses un equipo de modelos para ilustrar “nuestro equipo”, una oficina que no es la tuya o un plato que no sirves. Aunque el texto no afirme que es real, el contexto puede sugerirlo.

Busca escenas sobrias y coherentes con el entorno del negocio. Las imágenes demasiado reconocibles, posadas o repetidas en otras webs hacen que la página parezca intercambiable.

## Decide por sección

| Sección | Opción preferible | Motivo |
|---|---|---|
| Primera pantalla | Foto propia si el espacio, producto o persona importa | Presenta la realidad desde el inicio |
| Equipo | Foto propia | Identifica a quien atenderá |
| Servicios abstractos | Stock, ilustración o diagrama | Puede explicar una idea sin fingir evidencia |
| Portfolio | Material propio con permiso | Demuestra el tipo de trabajo |
| Testimonio | Imagen autorizada o sin retrato | Evita atribuciones falsas |
| Artículo de blog | Propia, stock o gráfica original | Depende de la función editorial |
| Contacto y ubicación | Foto propia del exterior o acceso | Ayuda a reconocer el lugar |

La decisión también depende del presupuesto. Si solo puedes producir cinco buenas fotos, úsalas donde resuelvan más dudas y completa el resto con diseño, color o gráficos sencillos. No es obligatorio llenar cada bloque con una imagen.

## Cómo preparar una sesión profesional

Antes de contratar fotografía, crea una lista basada en las páginas. Para cada imagen, anota:

- Qué debe mostrar.
- En qué orientación se usará.
- Si necesita espacio para texto.
- Quién debe aparecer y qué permiso hace falta.
- Qué objetos, uniforme o preparación requiere.
- Qué versión horizontal y vertical necesitas.

Incluye escenas de contexto y detalles. Una peluquería puede necesitar exterior, recepción, estaciones de trabajo, equipo, proceso y resultados autorizados. Un consultor puede necesitar retrato, reunión y elementos de trabajo, sin recrear una oficina que no usa.

Pide los originales y acuerda por escrito los usos permitidos. Guarda también una selección optimizada para web, pero conserva los archivos de mayor calidad fuera del gestor de contenidos.

## Una sesión sencilla con móvil

Si no hay presupuesto para fotógrafo, un teléfono reciente y una buena preparación pueden producir material digno para una primera versión.

1. Limpia la lente.
2. Aprovecha luz natural suave y evita mezclar luces de colores distintos.
3. Ordena el fondo y retira carteles o datos que no deban aparecer.
4. Toma varias distancias y orientaciones.
5. Mantén el móvil estable y evita el zoom digital.
6. Fotografía acciones reales en lugar de poses forzadas.
7. Revisa enfoque, reflejos y elementos cortados antes de terminar.

No apliques filtros que cambien el color real de un producto, un tratamiento o un acabado. Ajustar exposición y recorte puede mejorar la imagen; alterar el resultado puede engañar.

## Permisos y privacidad

Confirma que puedes publicar imágenes de personas, clientes, menores, obras o espacios de terceros. El permiso debe corresponder al uso previsto. Si el contexto es sensible, busca asesoramiento adecuado en lugar de asumir que una autorización verbal es suficiente.

Revisa fondos y pantallas. Un documento, matrícula, dirección o nombre visible puede revelar información que nadie pretendía publicar.

Con las imágenes de stock, conserva la licencia y una copia de las condiciones aplicables en el momento de descarga. “Encontrada en Google” no significa disponible para uso comercial.

## Prepara los archivos para la web

Subir el original de la cámara suele añadir peso innecesario. Exporta cada foto al tamaño que se mostrará, genera variantes para pantallas distintas y usa un formato moderno compatible con la implementación.

El nombre del archivo debe describirlo, por ejemplo `equipo-taller-barcelona.webp`, sin convertirlo en una cadena de palabras clave. El texto alternativo describe lo que aparece y la función de la imagen. Si es decorativa y no añade información, puede llevar un alt vacío en la implementación.

No incrustes horarios, precios o frases esenciales dentro de la fotografía. Ese texto será difícil de actualizar, buscar, traducir y leer con tecnologías de apoyo.

## Evita una web visualmente repetitiva

Una galería con muchas tomas casi iguales no genera más confianza. Selecciona imágenes que aporten información distinta. Alterna vistas generales, detalles y proceso, manteniendo una luz y edición coherentes.

La [página de inicio](/blog/que-incluir-pagina-inicio-negocio-local) puede mostrar una selección breve y enviar a una galería o proyecto cuando el cliente necesite profundizar. Los [elementos de confianza](/blog/elementos-confianza-pagina-web) deben trabajar juntos, no depender de una única foto heroica.

## Una prueba antes de publicar

Enseña cada imagen sin su texto a una persona ajena al negocio. Pregunta qué cree que representa. Si interpreta una oficina de stock como el local real, existe riesgo de confusión. Si no entiende qué trabajo muestra una foto propia, añade contexto o elige otra toma.
