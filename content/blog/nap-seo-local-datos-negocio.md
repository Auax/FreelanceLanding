NAP son las siglas en inglés de nombre, dirección y teléfono. En SEO local se usa para hablar de los datos básicos con los que un cliente identifica y contacta a un negocio. Deben ser correctos y coherentes en la web, el Perfil de Empresa de Google y los directorios importantes.

La meta no es que cada coma o abreviatura sea idéntica. Lo importante es evitar contradicciones reales: dos teléfonos activos sin explicación, una dirección antigua, un nombre comercial diferente en cada plataforma o un horario que lleva al cliente a una puerta cerrada.

## Qué incluye el NAP

El núcleo es pequeño:

- **Nombre:** la denominación que el negocio usa en el mundo real.
- **Dirección:** la ubicación donde atiende, si existe un establecimiento abierto al público.
- **Teléfono:** un número atendido por el negocio y adecuado para esa ubicación.

En una auditoría conviene ampliar el control a la URL, horarios, categoría, correo, enlace de reserva y áreas de servicio. No forman parte de las siglas, pero una inconsistencia en cualquiera de ellos también perjudica la experiencia.

Google pide que el perfil represente el negocio tal como se presenta fuera de internet. Añadir servicios o localidades al nombre solo para incluir palabras clave puede incumplir sus directrices si esos términos no forman parte del nombre real.

## Por qué una discrepancia importa

Imagina que una persona encuentra una ficha con un teléfono, entra en la web y ve otro. Puede pensar que uno está desactualizado o que ha llegado al negocio equivocado. Si el mapa apunta al local anterior, el problema ya no es solo de visibilidad: hay una visita perdida.

Los errores más costosos suelen ser prácticos:

- llamadas que llegan a una línea desconectada;
- clientes que se desplazan a una dirección antigua;
- perfiles duplicados con reseñas repartidas;
- horarios diferentes en la web y en Maps;
- formularios o enlaces de reserva que pertenecen a otra sede.

La coherencia ayuda a que las plataformas y las personas conecten las distintas menciones con una misma entidad. No convierte por sí sola un perfil en el primer resultado, pero elimina señales contradictorias y fricción.

## Crea una ficha maestra antes de corregir nada

Decide cuál es la información oficial y guárdala en un documento compartido. Para cada sede, registra:

| Campo | Valor oficial | Responsable | Última revisión |

| Nombre comercial |  |  |  |
| Dirección completa |  |  |  |
| Teléfono principal |  |  |  |
| URL de la sede |  |  |  |
| Horario habitual |  |  |  |

Incluye decisiones que suelen generar dudas. Por ejemplo, si el rótulo muestra una marca corta pero la razón social es más larga, define qué nombre debe ver el público y dónde corresponde mostrar la información legal.

En negocios de área de servicio, la dirección requiere cuidado. Si no se atiende a clientes en el domicilio, no conviene presentarlo como local visitable. Configura el área de servicio según las reglas de la plataforma y explica en la web cómo se presta el servicio.

## Cómo hacer una auditoría manual

### 1. Revisa la propia web

Comprueba cabecera, pie, página de contacto, avisos legales y páginas de ubicación. Busca también el número antiguo dentro del código o de entradas del blog. Una búsqueda del dominio entre comillas puede descubrir páginas olvidadas.

### 2. Revisa el Perfil de Empresa de Google

Confirma nombre, categoría, dirección o área de servicio, teléfono, web y horarios. Comprueba los horarios especiales antes de festivos. Si existen varias sedes, revisa cada ficha por separado.

### 3. Busca variaciones del negocio

Haz búsquedas con el nombre actual, nombres anteriores, teléfonos y direcciones. Anota los directorios, perfiles sociales, asociaciones y medios que aparezcan. Prioriza los que reciben visitas o tienen relevancia para el sector y la ciudad.

### 4. Detecta duplicados

Dos fichas para la misma ubicación pueden confundir a clientes y repartir reseñas. No borres ni reclames nada a ciegas. Confirma primero si se trata de una sede distinta, una ficha antigua o una duplicación y sigue el proceso de la plataforma.

### 5. Corrige de mayor a menor impacto

Empieza por la web y el Perfil de Empresa. Continúa con directorios sectoriales, redes activas y plataformas que aparecen al buscar la marca. No necesitas perseguir cada recopilador desconocido si no tiene visibilidad ni uso real.

## Cuánta uniformidad necesitas

“Calle Mallorca, 10” y “C/ Mallorca 10” suelen describir el mismo lugar. No pierdas horas corrigiendo diferencias tipográficas inocuas mientras queda publicado un teléfono equivocado.

Usa esta prioridad:

1. exactitud del dato;
2. correspondencia con la ubicación real;
3. coherencia del nombre comercial;
4. canales de contacto que funcionan;
5. formato homogéneo cuando sea fácil mantenerlo.

Después de corregir, prueba los enlaces y llama al número desde un móvil. La auditoría termina cuando la ruta del cliente funciona, no cuando la hoja de cálculo está completa.

## Cuándo repetir la revisión

Revisa el NAP después de una mudanza, cambio de teléfono, nueva sede, reforma prolongada o modificación de horarios. Añade una comprobación breve antes de festivos y una revisión periódica de los perfiles más visibles.
